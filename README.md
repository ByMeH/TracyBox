# TraceBox

TraceBox — локальное настольное приложение на PyQt6 для ведения CTF-соревнований и заданий. Оно помогает хранить заметки и сведения об исследуемых файлах, выполнять базовые операции с текстом и файлами и экспортировать отчёт по соревнованию.

Приложение работает офлайн: для обычной работы не нужны интернет, сервер и внешние AI API. Все данные хранятся в локальной базе SQLite.

## Возможности

- Обзор: общее число соревнований и заданий, распределение по статусам, процент решённых и последние задания.
- Соревнования: создание, просмотр, изменение и удаление.
- Задания: привязка к соревнованию, категория, сложность (Лёгкая / Средняя / Сложная), статус (Новое / В работе / Решено / Пропущено), баллы и описание.
- Заметки: произвольные записи по каждому заданию.
- Артефакты: сведения о выбранном файле — путь, имя, размер, SHA-256. Исходный файл не копируется и не изменяется.
- Хеширование: MD5, SHA-1 и SHA-256 для выбранного файла с потоковым чтением.
- Кодировщики: Base64, Hex и URL-кодирование и декодирование.
- Экспорт: отчёт по выбранному соревнованию в CSV (список заданий) или TXT (полный отчёт с заметками и файлами).

## Технологии

- Python 3.14
- PyQt6 — графический интерфейс
- SQLite (`sqlite3`) — хранение данных
- PyInstaller — сборка Windows EXE
- pytest — тесты

## Структура проекта

```
TraceBox/
├── main.py            # точка входа и пути к ресурсам
├── main_window.py     # главное окно, вкладки и обработчики

├── tests/             # тесты pytest
├── docs/              # документы проекта
```

## Установка

```bash
python -m venv .venv
source .venv/bin/activate        # Linux, macOS
# .venv\Scripts\activate         # Windows
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Тестирование

```bash
pytest -q
```

## Расположение базы данных

База создаётся автоматически при первом запуске:

- Linux и macOS: `~/.tracebox/tracebox.db`
- Windows: `C:\Users\<имя>\.tracebox\tracebox.db`

Удаление этого каталога сбрасывает данные приложения. Файлы на диске, которые пользователь указал в артефактах, при этом не затрагиваются.

## Windows EXE через GitHub Actions

Сборка Windows EXE выполняется в GitHub Actions:

1. Открой вкладку **Actions** в репозитории.
2. Выбери workflow **Build Windows EXE**.
3. Нажми **Run workflow** (или запусти push-сборку в ветку `main`).
4. После завершения работы скачай артефакт `TraceBox` — он содержит `dist/TraceBox.exe`.

Workflow запускает тесты `pytest -q`, собирает однофайловое оконное приложение через `TraceBox.spec` (PyInstaller, `--onefile`, `--windowed`, включение `assets/tracebox.svg`) и публикует `dist/TraceBox.exe` как артефакт. Собранная Windows EXE не запускалась — сборка выполняется на Windows runner, проверку exe на чистой Windows-среде нужно выполнить вручную после скачивания артефакта.
